# 0.5.10

- **A bell for what you missed.** When you come back, the list of what happened no longer pops up over the office. A bell at the top shows how many things you missed. Click it when you want to see them.
- **Less to read.** If you already answered a chat in your coding app, it isn't counted as missed.
- **Clearer names.** Helpers that T3 Code starts for you now show your project's name instead of a long code.
- **Updates in the office.** When a new version is ready, a note like this one appears in the corner. It stays until you close it.
