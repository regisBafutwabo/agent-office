# 0.5.10

- **A bell for what you missed.** When you come back, the list of what happened no longer pops up over the office. A bell at the top shows how many things you missed. Click it when you want to see them.
- **Less to read.** If you already answered a chat in your coding app, it isn't counted as missed.
- **Clearer names.** Helpers that T3 Code starts for you now show your project's name instead of a long code.
- **Updates in the office.** When a new version is ready, a note like this one appears in the corner. It stays until you close it.
- **Room for everyone.** When every desk is taken, helpers sit in the lounge and meeting room instead of sharing a desk. If the floor is still full, a second floor opens for the same project.
- **One floor per project.** Helpers working on copies of the same project now sit together on that project's floor.
- **No more blank window.** The app no longer opens to a white screen when it starts.
- **They run when you call.** Call an agent that's on a break, even up on the roof, and it sprints back to its desk in a cloud of dust and slides into its chair.
